# holbertonschool-printf

## Description

Custom implementation of the C `printf` function for Holberton School.

## Supported specifiers

- `%c` — Character
- `%s` — String
- `%d`, `%i` — Integer
- `%%` — Percent sign

## Compilation

`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
